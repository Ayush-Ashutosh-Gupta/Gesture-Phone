# GesturePhone

GesturePhone lets users control their Android device using hand gestures detected through the camera. It combines on-device hand tracking with Accessibility services for touchless interaction.

## Features

- Real-time hand tracking (MediaPipe)
- Virtual cursor control
- Pinch to click / drag
- Media controls
- Volume and brightness control
- System actions (Back, Home, etc.)
- Custom gesture mapping
- Optional personal calibration
- Floating overlay support

## Example Gestures

- Index point → Move cursor
- Pinch → Click
- Fist → Play / Pause
- Swipes → Scroll / Media
- Thumbs up/down → Volume

## Tech Stack

- Kotlin
- Jetpack Compose
- MediaPipe Hands
- CameraX
- Accessibility Service

## Purpose

An experimental utility focused on hands-free control and accessibility-style interaction.
